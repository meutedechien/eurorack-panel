# Faces avant Eurorack

Dessinez les faces avant de vos modules Eurorack directement dans le navigateur : choix de la largeur en HP, glisser-déposer des jacks, potentiomètres, interrupteurs et LED, puis export en SVG pour la découpe ou la gravure laser.

**▶ Utiliser l'app : https://meutedechien.github.io/eurorack-panel/**

Une seule page HTML, sans installation ni serveur. Pour la modifier, forkez le dépôt et éditez `index.html`.
